Preserve Vault (Manifest V3 Chrome Extension)

Preserve Vault protects your work from internet loss, browser crashes, or accidental closes. It auto-saves your typing data every 5 seconds on any website. Perfect for freelancers, students, and remote workers to instantly restore drafts and eliminate lost progress.


- Auto-Save Mechanics: Automatically captures text inputs, textareas, and contenteditable elements.
- Dual-Layer Safety: Secure data persistence utilizing `chrome.storage.local` and browser `localStorage`.
-Decoupled Architecture:Real-time messaging background scripts, content scripts, and active browser tabs.
- Management Dashboard:Features advanced search, sorting, dark/light theme, and automated stale-data recycling.

 Tech Stack
- Languages: JavaScript (ES6+), HTML5, CSS3
- APIs:Chrome Extension Manifest V3 (Storage, Runtime, Tabs, Alarms API), DOM Manipulation, MutationObserver

How to Install
1. Download this repository as a ZIP file and extract it.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** (top-right toggle switch).
4. Click on **Load unpacked** (top-left button) and select the extracted project folder.
